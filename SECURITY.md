# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases (pre-1.0) | No |

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** button on the Security tab (private security advisory). Do not open a public issue.

We aim to respond within 72 hours.

## Scope

- The backup/restore engine
- The installer
- The CWP admin module

## Please never post publicly

Storage keys, restic passwords, or unredacted logs. Redact them in any report.
